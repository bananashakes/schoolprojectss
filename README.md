# School Projects | Applied AI

A collection of academic projects developed during my Diploma in Applied Artificial Intelligence at Temasek Polytechnic.

This repository documents my work across software development, machine learning, cloud computing, mobile applications and robotic process automation.

## Projects

| Project | Description |
|---|---|
| **MLDP – Developer Salary Prediction** | Machine learning regression project predicting developer salaries using survey data, model comparison and hyperparameter tuning. |
| **CTAI – MemeMatch** | Serverless web application using facial emotion recognition to recommend memes. |
| **MBAP – AuraFarm** | Flutter mobile application developed for my Mobile Applications Development project. |
| **ADEV / DBAV – Animal Adoption** | Animal adoption web application with database integration and administrative features. |
| **DSAG** | Data science and analytics coursework using Python and Jupyter notebooks. |

## About

These projects reflect my learning and practical experience in building, testing and documenting software solutions.

Each project is organised into its own folder, with source code and supporting documentation where available.
