# MLDP — Developer Salary Prediction

Machine Learning for Developers (CAI2C08) | Temasek Polytechnic

This project explores the use of supervised machine learning to predict annual software developer salaries using data from the 2025 Stack Overflow Developer Survey.

The project covers exploratory data analysis, preprocessing, feature engineering, regression model comparison, hyperparameter tuning and evaluation.

## Recommended Version

**Please refer to [`salary_5.2.ipynb`](salary_5.2.ipynb) as the final version of this project.**

Earlier notebooks have been retained to document the development process, experiments and improvements made throughout the project.

Version 5.2 includes refinements to salary filtering, feature selection and model development.
